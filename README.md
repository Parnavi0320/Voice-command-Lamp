# Voice-Controlled LED System Using ESP32

## Project Overview
This project uses voice commands to control four LEDs with an ESP32 DevKit V1, an INMP441 microphone, and an Edge Impulse audio classification model.

## Hardware Components
- ESP32 DevKit V1
- INMP441 I2S microphone
- Red LED
- Yellow LED
- Purple LED
- White LED
- Current-limiting resistors
- Jumper wires

## Features
- Voice-controlled LED switching
- Individual color selection
- Three brightness levels: 100%, 50%, and 20%
- All LEDs ON and OFF commands
- Voice recognition using Edge Impulse

## Pin Connections

| Component | ESP32 GPIO |
|---|---|
| Red LED | 18 |
| Yellow LED | 19 |
| Purple LED | 23 |
| White LED | 22 |
| INMP441 BCLK | 26 |
| INMP441 WS | 25 |
| INMP441 SD | 33 |

## Software Requirements
- Arduino IDE
- ESP32 Arduino board package (Core 3.x)
- Generated Edge Impulse Arduino library

## How to Run
1. Install Arduino IDE and the ESP32 board package.
2. Install the Arduino library generated by your Edge Impulse project.
3. Open `Voice_Controlled_LED_System.ino`.
4. Select **ESP32 Dev Module** and the correct port.
5. Verify and upload the code.
6. Open Serial Monitor at 115200 baud.
7. Speak commands supported by your trained model.

## Note
The Edge Impulse model, audio sample format, and sampling configuration must match the code for correct operation.
